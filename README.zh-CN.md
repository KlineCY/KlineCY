## 研究项目

### CTA多资产多空策略

围绕美国股票、国际股票、固定收益、商品及另类资产等类别的37只ETF，构建动量、趋势与波动率等六类预测特征，并在逐月滚动框架中比较七类预测模型。研究以验证集表现选择Ridge模型，结合Ledoit–Wolf协方差估计与考虑风险、换手和敞口约束的组合优化方法形成多空仓位。

### DICE模型研究

在复旦大学经济学院经岚计划中，独立撰写关于DICE模型提出、演变及现实价值的研究论文，梳理模型的经济学逻辑、应用与局限。
